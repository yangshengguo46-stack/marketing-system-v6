# Shot Craft Behind the Production Plan

Use this method only after content and format are sealed and the user explicitly
asks to continue into video production. It makes plan
actions visually and sonically executable; it cannot rewrite the script or own
durable state.

## Project-level Direction

Before splitting shots, state only the rules that will affect execution:

- camera stance relative to the subject, product, and action;
- intended viewer experience;
- where pacing holds, compresses, or changes;
- composition rules that express hierarchy or contrast;
- motivated light/color behavior;
- roles of dialogue, practical sound, silence, music, and off-screen space;
- a short set of repeatable visual/sound motifs already supported by the
  sealed content.

Avoid prestige adjectives that do not change a shot. If a named creator or film
is supplied as reference, translate it into mechanics and keep the name out of
provider imitation prompts.

## Purpose and Deletion Test

Every shot must preserve a sealed piece of information, action, reaction,
emotion, transition, or recall. Ask: what is lost if this shot disappears?
Merge or remove shots with no defensible loss.

Useful neighboring-shot relations include:

- `progressive`: each shot adds information or intensity;
- `causal`: action/claim/reveal paired with its consequence;
- `contrast`: adjacency exposes a meaningful difference;
- `montage`: parallel fragments compress time or establish range;
- `standalone`: one shot completes the beat.

These are editing choices, not quotas.

## Action and Reaction

Choose a legible relation for important causal beats:

- action then reaction for clarity;
- reaction before cause for a short information gap;
- several actions then one reaction for accumulation;
- off-screen action with visible reaction;
- delayed reaction when immediacy would feel false;
- action and reaction in one frame when spatial relation matters;
- intentionally omitted reaction for an unresolved cut.

## Review Board

For each planned shot, show the smallest useful review projection:

| Field | Question |
|---|---|
| Plan binding | Which action, asset, assembly step, and sealed content does this execute? |
| Time | What interval or duration does it occupy? |
| Camera | Angle, size, movement, and focus only where consequential |
| Visible action | What can actually be seen? |
| Space/light | Where does it happen and what motivates visibility? |
| Sound | Dialogue/VO reference, practical sound, silence, or music role |
| Transition | What connects it to neighbors? |
| Purpose | What would be lost if deleted? |
| Source route | User material, capture, deterministic graphics, or an exactly sealed generation request (plus approval only after registration) |

The board is for human review. The existing validated `ProductionPlan` and
provider/task receipts remain authoritative; never create a second shot ledger
or parse the table back as truth.

## Provider Handoff

Build generation prompts only from observable shot mechanics and sealed
content. Check that visible claims have exact upstream support, references have
rights, duration can contain the action, controls do not conflict, and no text,
logo, likeness, voice, or product behavior was silently added.
