# ADR-009：配置化搜索与证据角色隔离

- 状态：采用
- 日期：2026-08-15
- 证据：`LEDGER.md` A24
- 后续说明：A25/ADR-010 已确认并开始接入抖音开放平台视频搜索；本文件保留 2026-08-15 当时“尚未取得权限”的历史审计，不再代表当前权限状态。

## 背景

内容根已经冻结后，搜索仍可能因查询污染、低质结果或供应商不可用而让最终答案跑偏。旧工具声明使用当前配置，实际却硬编码 DuckDuckGo；地图查询还机械追加“人物、事件、作品、记录”，真实搜索因此返回作文素材和时间线工具。普通搜索结果也缺少明确角色，存在把一条视频或账号页误读成对标账号分析的风险。

## 决策

1. 研究层调用运营者配置的 `web_search`，并兼容标准结果、列表结果和字节 `Result.WebResults` 回执。
2. 地图方向查询只包含冻结根与实际方向，不追加泛化词表。搜索仍与模型命名联想并行，但失败、弱证据或合同错误只能保留地图或弃权，不能改根。
3. 所有普通公开搜索回执固定标记为 `topic_evidence`。即使 URL 指向视频或账号页，也不能推断账号定位、受众、内容模式或成绩。
4. 对标账号使用独立账号身份、多作品采集和覆盖回执；咨询资料与对标证据不能靠模型猜测互相升级。
5. 增加可选的字节官方 Web Search 适配器。它只读取独立 `WEB_SEARCH_API_KEY`，不复用 `VOLCENGINE_API_KEY` 等 Ark 模型密钥。

## 官方能力边界

- [字节官方 Web Search Skill](https://github.com/bytedance/agentkit-samples/blob/main/skills/byted-web-search/SKILL.md)公开的基础搜索类型是网页与图片，并要求搜索专用凭证。
- [联网问答 Agent 更新记录](https://www.volcengine.com/docs/85508/1510771)说明抖音视频卡片属于另一产品能力。
- [抖音视频授权指南](https://www.volcengine.com/docs/85508/1512692)说明该能力当前需要移动端 SDK、企业与内容资质、售前评估和后台开通。因此不能把豆包 Chat 客户端可见的视频搜索等同于普通 Ark 或 Web Search API 权限。

## 验收

- 污染查询的五条真实结果中三条偏到作文素材或时间线工具；删除泛词后测试锁定查询只使用根与地图方向。
- 当前 DDG 中文结果仍会混入低质页面，因此只作为降级提供方，不据此放宽证据合同。
- 一次完整黄金运行中六次外部搜索全部失败；根在搜索前后保持一致，来源为空，`TopicBrief` 保持为空。系统没有用模型常识补造题目。
- 2026-08-15 的 Ark Responses 内置 `web_search` 返回 `ToolNotOpen`；当时本机没有搜索专用 Key，因此字节适配器只完成实现与测试，没有启用。
- 2026-08-19 使用后来提供的独立搜索 Key 完成真实只读验收：字节 Web Search 鉴权成功并返回网页结果；`SearchType=video` 明确返回 `10402 invalid search type`。包含爱奇艺或 B 站链接的网页结果仍是 `WebResults`，不是结构化视频搜索；两组定向查询取得的抖音作品直链均为 `0`。该凭证只解锁普通网页题材证据，不解锁抖音视频或对标账号证据。

## 后果

- 更换搜索供应商无需改内容智能业务代码。
- 正式启用字节搜索前必须由用户在官方控制台开通并把专用 Key 放入本地未跟踪配置。
- 搜索可以发现对标账号候选，但不能完成对标分析；后者继续由账号采集模块负责。
- 联网问答 Agent Pro 的抖音视频卡片属于另一产品合同，还需要已发布 Bot、`bot_id` 和抖音视频权限配置；不能由本 ADR 的 Web Search Key 自动获得。
