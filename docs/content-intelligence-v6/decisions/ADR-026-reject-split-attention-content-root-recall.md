# ADR-026：拒绝分离注意力内容根召回进入运行时

## 状态

Rejected，2026-08-19。

## 决定

拒绝将 `experiments/content_root_recall_lab` 的双工作者分离注意力方案接入 Lead、Tool、Skill、MCP、
中间件、生产子智能体或现役内容根链路。现役运行时和核心提示词保持不变，暂不把 A90 候选交给抖音对标验证。

## 理由

- 冻结严格评分中，单工作者和双工作者都为 `0/16`；人工近义概念复核后分别为 `9/16` 和 `3/16`，
  双工作者没有提升，反而少六组。
- 双工作者只完成 `5/12` 合同，低于单工作者的 `8/12`，远低于冻结的 `12/12` 门槛。
- 分工读者把内容根下钻成阅读角、骨灰寄存、节日祭扫等内容地图节点；单工作者也生成具体路线、人物、作品
  与事件。实验没有守住内容根、内容地图和选题的层级边界。
- 关闭联网后仍出现无来源数字和历史断言，事实边界未通过人工复核。
- 双工作者使用 41,362 Token，是单工作者 24,144 Token 的约 1.71 倍，没有换来质量收益。
- 多 Agent 可以隔离注意力，却不能自动获得“哪个语义层级可成长为长期内容世界”的营销判断。

## 后果

- A90 十二题和唯一运行已经消费，不得调参、改合同、放宽别名或更换模型后重跑。
- A90 原始证据保留，失败草稿未保留的可观测性缺口必须在任何新实验前解决。
- 不将字典、抖音对标、内容地图、账号定位或更多子 Agent 叠加到 A90 上。
- 可复用并行重叠测试、确定性来源绑定、输入预算预检、请求与 Token 计数。
- 后续若继续研究，只允许新的薄候选合同：少量同层语义候选，代码推导路径端点，模型不展开地图、不写事实、
  不排序选根；必须使用新案例并重新预注册。
