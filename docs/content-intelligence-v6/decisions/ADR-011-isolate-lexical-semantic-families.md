# ADR-011：隔离词法主词、语义核与内容根

- 状态：采用
- 日期：2026-08-16
- 证据：`LEDGER.md` A28-A29

## 背景

A28 的黄金礼品端到端运行在技术上成功，却仍将内容根和几乎全部地图限制在黄金、礼品和馈赠。用户复核明确否定该结论：真正的语义路径应继续从“礼品”进入“礼”，再扩展到礼貌、礼节、礼仪、礼制、礼乐、礼崩乐坏以及人与人如何相处。

原语义阅读工作者同时看到商业对象、材质、活动和礼赠场景。即使合同要求它继续找意义核，高显著商业上下文仍会把联想吸回送礼、回礼和彩礼。这不是缺行业知识，而是词法主词、语义核和内容根被同一上下文混为一层。

## 决策

1. 商业语义阅读只负责原始对象、词法主词、修饰关系、对象角色、完整被服务对象、活动、功能和场景。它不再负责词内语义家族。
2. 新增一个有界的隔离词义工作者。它的唯一数据输入是 `lexical_head`，不得看到用户、业务、行业、修饰语、活动或起号请求。它同时输出真子成分和已绑定的跨域语义分支，不产生内容根或地图。
3. 代码只保留 `lexical_head` 的严格真子串，删除整词、外部词、重复成分和未精确绑定的分支。词内成分可以作为审计记录保留，但只有 `social_relation`、`cultural_institution` 和 `human_concern` 可触发跨域语义家族。`human_activity` 由业务语义层单独读取，不通过拆词向外联想。
4. `cultural_institution` 只指人类形成的规范、制度或仪式；自然物、地域、水域、材质和来源不属于该类。`social_relation` 必须是人或社会角色之间的关系；`human_concern` 必须是可反复面对的人类问题，不是感官属性。
5. 共同世界工作者使用两种互斥模式。有合格语义核时，只接收语义核和语义家族；没有时，只接收去修饰主词的直接活动、功能和场景。语义家族模式必须覆盖多个实质不同的分支，并用普通人能理解的生活问题命名，不得退回单一商品活动或抽象学术术语。
6. 根候选由代码从原对象、词法主词、语义核、完整被服务对象、直接活动、功能和已审共同世界确定性装配。地图与总编仍只看冻结根，不得看上游商品和语义跳转。
7. 商业对象和词法主词必须原样摘录用户表达。中间实现物与经营容器的 `served_objects` 必须使用最小完整通用名称；可移除的地域、材质、价格或人群修饰只是地图分支，不继承到内容根。
8. 仅对可空的共同世界字段兼容供应商返回的字符串 `null`、`none` 和空字符串，将其正规化为真正空值；其他结构仍严格校验。

## 验收

同一 `glm-5-2-260617`、关闭供应商隐藏思考、无联网搜索的真实回归中：

```text
黄金礼品 -> 礼品 -> 礼
  -> 礼尚往来 / 礼贤下士 / 先礼后兵 / 礼崩乐坏 / 克己复礼
  -> 人们如何用共同规矩组织人与人的相处

海鲜 -> 海鲜（无语义家族）
水果店 -> 水果（经营容器退后）
重庆火锅底料 -> 底料 -> 火锅（地域修饰退后）
```

黄金地图不再出现黄金工艺、成色、保值或产品目录；赠礼只是互惠关系中的一个分支，地图同时展开尊重与招纳、协商与强制、秩序崩塌、自我约束、跨文化比较、人际关系类型、历史文本和现代礼节。聚焦内容智能测试为 `55 passed`。

## 后果与限制

- 每个宽泛内容世界请求增加一次小型隔离词义调用。它替代原语义工作者中的词内家族职责，不是在旧提示上叠加同一责任。
- 本决策只批准语义核与冻结地图候选。它不证明完整起号、联网选题、表现形式、商业化或发布闭环已通过。
- 黄金礼品和三个对照案例均只冻结了一次最终真实回归。仍需新的留出词组验证词内角色分类的稳定性，禁止围绕这四个已看案例继续调参并宣称普遍最优。
- 具体人物、事件、经典文本、国礼与当代公共事件仍由根后搜索和证据阅读负责，不得把模型联想写成已取证事实。
