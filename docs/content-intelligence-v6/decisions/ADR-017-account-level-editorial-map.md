# ADR-017: 内容地图是账号级长期编辑定位

## 状态

`reviewed -> adopted for local canary; persistence pending`

## 背景

现有运行链虽然把 `ContentWorldView` 称为长期内容世界，但工程行为仍是“每次请求重新生成地图，
立即搜索一个题，再优先返回今日拍摄”。这会让一次搜索结果或实时热点事实上拥有定位权，也会把
“长期做什么 IP”退化成“今天做哪条视频”。

用户给出的水果店例子明确了目标：水果不是 SKU 展示目录，而是一种长期观察世界的入口。一个
具体题可以研究某地农民为何改种榴莲，背后连接种植者、土地、价格、贸易和人的选择；同一账号
的其他题仍应让观众认出同一个内容根与观察方法。

## 决策

1. `ContentWorldView` 定义为账号级内容地图，而不是每日选题结果。它新增
   `editorial_promise`、`recurring_lens` 和 `drift_boundaries`。
2. `content_root` 回答长期讲什么；`editorial_promise` 回答观众为何持续关注；
   `recurring_lens` 回答账号怎样反复观察具体人物、地方、事件与变化。表现形式仍在下游。
3. 地图生成不增加新模型调用。冻结根地图工作者在原有一次结构化调用中同时生成上述定位字段与
   长期内容疆域。
4. 地图通过 `content_map_version_id()` 内容寻址。版本包含内容根、观众领地、长期承诺、观察
   方法、防漂移边界和地图维度；后续新增已取证人物或事件不改变版本。
5. 每个 `TopicBrief` 必须绑定一个地图版本，且路径第一步必须从冻结内容根出发。联网证据、热点
   或命名联想可以补充具体题材，但不能改写地图。
6. 宽泛起号请求成功时先显示账号内容定位，再给一个地图内的“今日建议拍摄”。这条题是定位样例，
   不是用一次选题替代长期定位。
7. 热点不是独立内容根，也不是默认必选项。只有能沿既有地图路径被账号稳定观察方法解释时，才
   能作为当日候选；纯热度搬运留在地图外。

## 事实边界样例

“泰国老百姓为什么改稻为榴”是很强的内容地图方向，但标题中的“水稻”和全国范围需要单独取证。
当前检索到的泰国研究只直接支持呵叻府 Pak Chong 县 Khlong Muang 的三个果园从一般大田作物
转种榴莲，主要动因包括原作物售价低于成本、土地适宜、榴莲售价更高和市场支持；它不能独立证明
泰国农民普遍从水稻转种榴莲。

因此在取得稻田与具体地区证据之前，更严谨的候选是“为什么泰国一些农民把传统大田作物改种
榴莲”。泰国农业经济办公室的省级榴莲面积、产量与单产数据，以及农业推广部门对出口质量、
中国市场和生产管理的资料，可以继续补充背景，但不能替代作物转换证据。

## 拒绝的方案

- 每次起号请求只返回一个热点题：能做视频，不能形成稳定 IP。
- 让热点检索重新选择内容根：一次外部事件会破坏账号连续性。
- 把口播、短剧、图文写进 `recurring_lens`：混淆账号观察方法与表现形式。
- 新增独立定位 Agent：当前字段可由既有冻结地图调用承担，没有证据支持增加运行复杂度。
- 把商品、成交或商业回桥写进地图版本：会重演内容不断回到商品的旧问题。

## 验证与限制

- 失败测试先证明旧合同没有长期承诺、观察方法、版本绑定和定位优先渲染。
- 第一次真实端到端水果店探针暴露根裁决缺口：模型把“顾客选购水果”当成了比“水果”更大的
  长期世界。根裁决现在区分“获得一个完整对象的交易步骤”和“经营容器让人进入的完整活动”。
- 同一 `glm-5-2-260617`、同一干净问题“我是开水果店的，我要怎么起号？”在修正后选择“水果”为内容根，
  并生成“品种谱系与物种身份”、“地理迁徙与产区演化”、“种植方式与果农选择”、“流通与价格形成”、
  “文化与历史意义”等长期疆域。这使果农为何改种某种水果成为地图内自然分支，而不是外挂热点。
- 实现后内容智能聚焦回归为 `97 passed`。详见
  `evidence/account-editorial-map-a36-2026-08-16.md`。
- `ContentWorldView` 已可内容寻址，但账号级数据库持久化、用户确认和版本切换尚未实现。
- 热点源尚未建成独立合同；当前只能作为普通 `topic_evidence` 进入地图后的取证链，不能宣称已完成
  热点运营。
