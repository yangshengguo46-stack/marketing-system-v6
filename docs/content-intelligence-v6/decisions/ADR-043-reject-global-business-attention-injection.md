# ADR-043 否决全局业务注意力注入

## 决定

不把 A132 的业务注意力卡接入现役 Lead Prompt、Middleware 或 Skill。保持当前 DeerFlow Agent 与渐进式
Skill 发现方式不变，将该卡的七项业务维度仅用于离线评测和人工复核。

## 原因

A132 两臂的模型、基础 Prompt、工具、Schema、Skill、MCP 路由和中间件合同一致，实验有效；候选仍只在
六个 held-out 中获得三个裁判偏好，平均得分 `-0.167`，并在旧衣纪念玩偶题产生 `-8` 分的重大回归。
候选还使 held-out Token 增加约 `6.4%`。

黄金礼品诊断中，现役 Agent 已能通过真实 Skill 路由从黄金礼品进入“人与人之间的相处与人情世故”，
候选只是小幅改善表达，并未提供现役缺失的核心能力。农用无人机题证明注意力维度有局部价值，童装题则
证明把它永久放在总脑里会导致过早澄清并压制已有业务洞察。局部收益不能抵消全局不稳定性。

## 后续约束

- A132 已消费，不重跑、不调参，不将七题答案写成生产示例。
- A132 Probe 继续留在 `backend/experiments/`，不得注册到 Gateway、Lead 或扩展配置。
- 未来若验证按需注意力，必须使用全新 held-out，并且候选应替换当轮上下文，而不是叠加另一层长提示词。
- 不为检测“回答是否够聪明”增加确定性业务闸门；业务质量继续由结果评测、真实数据和人工纠错校准。
- `PromptManifest` 若进入正式实现，只能观察并归账，不得修改模型输入或强制工具轨迹。
