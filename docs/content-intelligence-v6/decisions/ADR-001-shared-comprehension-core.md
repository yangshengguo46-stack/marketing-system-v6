# ADR-001：从共享阅读理解记录长出孵化能力

- 日期：2026-08-14
- 状态：accepted for evaluation

## 决策

第六版直接修改 DeerFlow 核心，增加可选 `analyze_content_intelligence` 工具和薄 Lead 契约。工具通过一次结构化模型调用构建 `ComprehensionRecord`，再绑定商业语义、内容世界和选题简报三个可选投影。Lead 仍拥有最终判断权。

## 原因

第五版证明单独堆提示词、方法 Skill、语义工具和内容地图工具会重复理解同一句用户表达，并在层间丢失主语、路径或证据。把三类产物合并成一个大流程又会形成新硬门。共享记录同时解决信息复用与职责隔离，而可选调用避免每轮强制执行。

## 明确拒绝

- 不迁移第五版工具源码和累积总提示词。
- 不把用户四个纠错案例或真实账号答案写入运行时提示词。
- 不要求固定工具轨迹、固定问题数、候选数、天数或实验。
- 不在当前阶段建立知识库或固定多 Agent 队伍。
- 不让语义、地图或选题投影决定表现形式、卖货和发布。

## 后续门槛

用相同模型、相同上下文预算和全新留出题比较模型直答、当前单次结构化候选及共享记录上的受控多 Agent 候选。只有业务理解、事实边界和具体选题同时改善，才继续扩展运行时。
