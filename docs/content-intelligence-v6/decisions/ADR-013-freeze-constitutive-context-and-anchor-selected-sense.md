# ADR-013：冻结构成语境，并锚定词内已选义项

## 状态

`adopted for local canary`，2026-08-16。

## 问题

A30 接入结构化词义证据后，陌生案例暴露出两个与向量召回无关的信息损失点。

第一，语义阅读者已经能判断某个修饰语是否改变人物、共同事件、关系结构或生命周期，但
共同世界工作者又独立重做同一判断。`宠物殡葬` 首跑中，上游将“宠物”判为构成语境，
下游却把它删除并提出“人与死亡之间的告别、遗体处理与哀悼”。该世界语义更宽，却错误
改变了参与者关系和业务对象。

第二，隔离词义工作者已经解释了某个子成分在整词中的实际含义，但共同世界输入只保留
成分名称与角色。`老年旅行团` 因此从“团”错误走到“团拜”，生成与旅行无关的节庆问候
世界。词典命中了正确整词和义项，错误发生在下游丢失已选义项之后。

## 决策

1. 修饰语的 `world_scope_effect` 由语义阅读者拥有。共同世界工作者接收冻结的
   `required_constitutive_contexts`，只负责合成，不再拥有推翻权。
2. 构成语境必须逐字进入共同世界合同和名称，并保留它造成的人物、事件、关系或生命周期
   差异。若模型漏掉，上下游意见不一致的泛化世界被确定性撤下，不进入根候选。
3. 该保护不自动拼接新名称，也不强迫模型选商品根；无法合成时保留已有候选并显示未知。
   这是跨工作者合同一致性，不是行业关键词门禁。
4. 隔离词义工作者的 `relation_to_subject` 经去除词法主词原文后，作为
   `selected_meaning_in_head` 传给共同世界。它是词族展开的锚点；具体 related expression
   只能证明语义范围，不能反客为主成为共同世界。
5. 集合、组织、群体或容器名称不因包含多人就自动成为 `social_relation`。社会关系必须
   直接表达角色之间的关系，而不是仅把人归成一组。
6. 不增加向量库、行业词表、固定答案或新的自由 Agent。词典仍只提供证据，根裁决仍在
   冻结候选上比较最大有效内容世界。
7. 共同世界是可选候选生成器。连续两次结构化输出不可用时，记录一个可见未知并继续使用
   对象、词法主词、完整被服务对象、活动和功能候选；可选节点不得拖死整个内容地图。

## 真实观察

- `黄金礼品` 回归为“人们以礼确立彼此位置与相处之道的世界”；“黄金”为分支限定，地图
  进入礼的类型、关系位置、历史、地域、哲学和当代实践。
- `重庆火锅底料` 回归为“火锅”；“重庆”为分支限定，“火锅”为构成语境。
- `宠物殡葬` 首跑错误删除宠物；一致性保护后保守回到“宠物殡葬”；职责冻结后开发复跑
  进入“人们为死去的宠物送殡安葬”，地图保留主人关系与丧宠心理。
- `婴儿辅食` 首跑进入“婴儿从流质到固体饮食过渡中的喂养照护”。
- `云南咖啡豆` 首跑将云南保留为分支，进入“亲手冲煮并品鉴咖啡风味的生活世界”。
- `亲子研学团` 在已选义项锚定后的首跑没有再出现团拜噪声，地图保留亲子共同体验、孩子
  成长与家庭关系；但语义阅读仍把“亲子”标为分支限定。这是公开残差，不算完全通过。
- 最后一轮火锅回归中，共同世界供应商连续两次返回空结构，原实现整条失败。加入可见降级
  后，单元测试证明仍可选择完整被服务对象；真实复跑正常返回并再次选择“火锅”。

开发修复后的重复案例不得冒充新保留集。逐次回执见
`evidence/constitutive-context-a31-2026-08-16.md`。

## 后果

同一语义判断不再由两个工作者互相覆盖，失败时也不会静默进入错误大世界。代价是：上游
语义阅读误判时，系统可能保守停在完整对象；这比伪造一个失去参与者关系的大世界更可审计。
当前词义证据只直接支持词法主词，尚未独立解释修饰语。是否增加修饰语精确义项复核，必须
先用新的关系型修饰语案例单独评测，不能因为“亲子”一例就再堆一个强制工作流。
