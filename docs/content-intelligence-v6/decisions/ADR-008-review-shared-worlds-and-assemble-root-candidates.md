# ADR-008：审查共同世界并由代码装配根候选

- 状态：采用
- 日期：2026-08-15
- 证据：`LEDGER.md` A22-A23

## 背景

ADR-007 将共同世界、候选召回和根裁决拆开后，黄金礼品仍会偶发生成“贵重赠予与价值传承”等带回黄金材质的混合世界。进一步收紧共同世界后，海鲜又被提升为待客，火锅底料被提升为聚餐涮菜。问题不是缺少更多行业知识，而是自由候选生成器仍可改名、拼接和放大普通使用场景，最终裁决又看不到候选究竟来自完整对象、普通动作还是功能。

## 决策

1. 语义阅读增加去修饰后的活动、功能和场景；依赖被移除修饰语的价值或场景不得回流。
2. 共同世界提出后，由另一次独立反事实审查判断主词是否为该实践的构成部分。可替换成大量无关对象的普通使用、消费、制作、交易或聚会场景不成立。
3. 删除自由根候选生成调用。代码只从语义合同原值装配对象、词法主词、完整被服务对象、活动、功能、通过审查的共同世界和示例分支，不改名、不合并。
4. 候选保留来源类型；最终裁决只看到对象角色及冻结的类型和名称，不接收候选自写的优势、风险或上游长解释。
5. 中间实现物若先指向另一个中间产物，语义阅读继续追到最终可独立识别、体验或参与的完整对象。

## 理由

- 反事实审查解决“泛社会场景看起来比对象更大”的问题，而不写行业关键词。
- 确定性装配消除候选工作者对自身造词的游说，也少一次模型调用。
- 候选来源类型为裁决恢复必要语义，同时不把完整上游记录重新塞回去。
- 这是可检查的语义边界，不是固定行业答案或评分硬门。

## 验收

同一 `glm-5-2-260617` 配置的最终无搜索真实回归：

```text
黄金礼品 -> 人际馈赠与礼物交换
海鲜 -> 海鲜
重庆火锅底料 -> 火锅
```

三题地图均只围绕冻结根展开。黄金没有退回材质、保值或婚庆五金；海鲜没有被待客或烹饪动作取代；底料穿过火锅汤底继续到完整对象火锅。聚焦测试为 `52 passed`。

## 后果

- 有共同世界提案时，根前仍是五次结构化调用：语义、共同世界、反事实审查、根裁决、地图；不存在提案时跳过审查。
- 共同世界审查可能拒绝一个有创意但过宽的候选。它只影响候选资格，原活动、功能和场景仍保留为地图材料或未知，不删除语义记录。
- 医美、场所、服务和素人等新类型仍需新的留出案例验证，不能从三题通过外推为全部业务通过。
