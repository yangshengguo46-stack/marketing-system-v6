# ADR-007：拆分共同世界、候选召回与根裁决

- 状态：部分被 ADR-008 取代
- 日期：2026-08-15
- 证据：`LEDGER.md` A21-A22

## 背景

A21 的黄金礼品运行在联网前已把“婚嫁礼俗”从一个具体场景提升为内容根。旧工作者同时生成候选、选择赢家和解释赢家；自然语言提示虽禁止窄场景与宽世界混合，结构合同却只验证赢家索引存在。相同输入的隔离探针在婚嫁、黄金赠礼和人情往来之间漂移，证明单次正确结果不可视为稳定能力。

## 决策

以下记录保留当时的职责拆分。ADR-008 后续以独立共同世界审查和确定性候选装配取代了第 3 步的自由模型召回；示例分支不可选和独立根裁决仍继续采用。

根前链路改为四个独立、受控上下文：

1. 字面语义阅读拆商业对象、词法主词、修饰、活动、功能和具体场景。
2. 跨场景共同世界只接收去修饰后的主词、参与活动和具体场景，提炼共同动作、参与者关系与共同世界；它看不到完整商品名、修饰语或商品价值功能。
3. 候选召回只列候选并标记 `root_candidate / example_branch`，不排名。共同世界若成立，确定性保证它出现在候选集合中。
4. 根裁决只在冻结的 `root_candidate` 子集中解释选择索引；代码拒绝把 `example_branch` 选为内容根或观众领地。

地图仍只接收最终冻结根，研究仍只能在地图之后发生，且不能改根。

## 理由

- 信息隔离比要求模型忽略高显著商品词更稳定。
- 将共同世界提炼与最终选择分开，避免一个工作者为自己生成的候选自证。
- `example_branch` 是语义结构边界，不是行业评分或运营硬门；它只阻止一个局部场景冒充整个商业表达的内容根。
- 共同世界仍只是平等候选，不会自动压过完整对象，因此海鲜、火锅、腕表等对象型世界仍可由裁决器选择。

## 不采用

- 不把“黄金礼品应进入人情往来”写进提示、关键词表或确定性行业规则。
- 不依赖增加搜索量修复根选择；错误根上的更多证据只会放大漂移。
- 不让搜索、内容地图或后续总编重新选择内容根。
- 不用固定候选数量、行业评分或强制抽象层级替代语义判断。

## 后果

- 根前结构化模型调用由三次增加为五次，换取可检查的共同世界、候选集合与独立裁决。
- 运行事件可分别定位字面阅读、共同世界、候选召回和裁决错误。
- 新链路必须先通过无搜索根与地图验收，再重新评估搜索和选题；旧 A21 搜索结果不能继承为新根的验收证据。
