# ADR-016: 在 MessagePlan 中加入有证据边界的讲述策划

## 状态

`reviewed -> adopted for local canary; quality acceptance pending`

## 背景

同一个古巴雪茄题材可以被讲得津津有味，也可以成为资料堆砌或冷笑话。差异不只在最终措辞，
而在更早的创意判断：从哪个事实进入、让观众跟着谁或什么看、留下什么诚实问题、按什么顺序
揭示信息，以及最终兑现什么新理解。

标题、开头和 UC 式“震惊体”只是注意力包装。包装可以制造点击，却不能替代视角、证据推进和
兑现；虚假信息差还会损害账号长期信任。

## 决策

1. 不新增一个自由行动的编剧 Agent，也不再增加必经工作流。现有扁平 `MessagePlanDraft` 增加
   `entry_point`、`telling_lens`、`audience_question`、`information_order` 和 `payoff`。
2. `TopicBrief` 仍拥有“讲什么”和事实边界；这些字段只拥有“从哪里讲、站在哪里讲、怎样揭示”。
   它们不得重选内容根、选题或中心判断。
3. 切入口只选一个主锚点，不把来源和背景列成目录。讲述视角可以沿人物、物件、关系、变化或
   对照组织材料，但不能发明材料。
4. 观众问题只能形成可兑现的信息差。标题和开头不得用“震惊、惊呆、不看后悔”等空壳词代替
   内容强度；`payoff` 必须回答观众问题并回到中心判断。
5. 用户职业或经营身份只决定观察角度，不要求把店铺、商品或成交写进正文。来源名称通常只留在
   参考资料；只有来源本身属于事件，或断言必须就地归因时才进入稿件。
6. `MessagePlan` 的稳定身份绑定完整讲述策划。同一 TopicBrief 即使标题相同，只要切入口或视角
   不同，也形成不同 `message_plan_id`。
7. 这仍是表现形式之前的讲述策划。它不决定口播、图文、短剧或纯素材，也不把非叙事内容强制
   改成故事。

## 被拒绝的方案

- 只在 Prompt 中要求“生动、有网感”：不可检查，也无法区分选题问题与讲法问题。
- 固定震惊体、悬念模板或标题公式：会优化点击包装而不是内容理解和长期信任。
- 为每条内容强制完整编剧因果链：历史解释、比较、知识答疑和评论不一定需要人物冲突。
- 新增一个可重新研究和改题的编剧 Agent：会与 TopicBrief 争夺选题权并重新制造多脑冲突。
- 用固定分数阻止成稿：质量审阅只能提供比较证据，不能成为语义硬门。

## 验证与限制

- 测试先行基线为 `5 failed, 1 passed`；实现后交付测试为 `6 passed`。
- 全部内容智能回归为 `93 passed`，Ruff 与 `git diff --check` 通过。
- 第一次真实 GLM 雪茄探针选中了“两位人物的雪茄都是视觉符号但意义不同”的对照视角，但把
  来源信息写成场景，正文偏资料汇报，并把“走进我的雪茄馆”塞进收束。
- 通用边界修正后，同一证据第二次真实调用选择丘吉尔反复出现的雪茄为唯一入口，场景保持空值，
  沿视觉道具观察两位人物，也不再插入店铺。结果已从资料罗列提升为有视角的解释。
- 第二次文案仍偏研究说明，缺少鲜活事件、动作、语言节奏和更强的人物材料。因此本 ADR 只采用
  可检查的讲述策划合同，不宣称已经达到“津津有味”的质量验收。
- 下一候选应比较“直接写稿”与“先形成讲述策划，再针对该角度补充场景/动作证据后写稿”。该
  补充研究回路尚未实现，不能写成当前能力。
