# ADR-042 否决 A130 的工具不一致晋级

## 决定

不把 A130 的 `focused_business` 注意力卡接入生产。保留其业务维度、薄上下文和盲评方法，下一轮改用
完整 DeerFlow 同工具 A/B。

## 原因

`current_full` 提示词要求按需发现 Skill，但 A130 明确关闭工具，导致三题基线出现重复循环。这个结果
测到的是“提示与工具合同不一致”的损害，而不是候选相对现役 Agent 的业务增益。其余有效案例也同时
出现真实提升、退步和事实编造，尚不足以晋级。

## 约束

- 不修改 A130 机器回执；以 A131 人工复核覆盖其自动晋级解释。
- 不在生产中新增业务 Middleware，不把注意力卡堆叠进核心 Prompt。
- 后继实验通过后，仍要决定是替换现役孵化段、动态加载上下文还是维持原状，不能从 A/B 胜出直接推导
  “永久追加提示词”。
