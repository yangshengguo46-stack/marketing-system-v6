# ADR-004：内容地图不拥有冲突，编剧脑位于证据之后

- 日期：2026-08-15
- 状态：accepted after focused and live evaluation

## 决策

内容地图只展开冻结根周围可研究的时间、空间、人物、事件、种类、文化、作品和关系，不设置“冲突”轴，不编排故事。文化差异、角色互动、协商、情绪或利益差异按实际关系表达，不能因为它们有张力就自动成为剧情。

证据阅读之后增加独立选题总编。它可以形成非叙事 TopicBrief；只有证据同时支持主体、具体目标、阻碍、行动或选择、代价、结果或变化时，才附加 `NarrativeFrame`。六项都必须引用 `ComprehensionRecord` 中真实存在的观察，缺项时保持为空。确定性合同验证引用，不用规则决定故事内容。

命名召回的 `why_worth_reading`、`relation_to_root` 和 `search_queries` 都是检索假设。证据阅读与选题总编不接收这些字段，只接收候选身份、命名对象、地图维度和规范化证据。最终路径理由与命名连接来自 TopicBrief 的证据机制，不得把召回猜测提升为已取证判断。

## 原因

婚礼与火锅运行曾把一般关系差异写成“博弈、潜在冲突”，原因是地图同时承担了发散方向与故事组织。两种任务使用同一词却含义不同：地图中的差异是可研究关系，编剧意义上的冲突则是“主体为了目标，在阻碍下采取行动并承担代价”的过程。把后者放进地图会迫使每个领域都制造对抗。

珠峰受控测试还暴露了第二个污染源。命名召回猜测希拉里与丹增的背景差异和功绩归属，证据只支持首次突击折返、第二次冲顶、越过冰岩障碍和最终登顶。旧输入要求总编兑现召回猜测，于是完整行动链被错误弃权。隔离召回理由后，总编能在同一人物内重新立题，并把来源未直述的失败代价明确标为推断限制。

## 不采用

- 不在地图中保留一个“冲突”子节点再靠提示解释其含义。
- 不把所有选题都强制改成故事，也不设置故事数量配额。
- 不用关键词替换器或行业规则决定哪里有剧情。
- 不让证据阅读器同时立题和写故事。
- 不让检索查询、召回理由或候选猜测进入事实槽。
- 不把选题级限制压进一段反面话术；`TopicBrief.limitations` 独立保存并展示。

## 验收

聚焦合同、地图、研究、工具、输入净化和终局交付测试共 `220 passed`。婚礼真实模型反例选择“婚礼仪式”，搜索失败后仅保留时间、地域、人物、仪式、文化与作品地图，没有叙事骨架。登山真实模型在没有命名证据时同样只保留地图。

使用英国皇家地理学会 1953 珠峰资料做受控证据测试后，DeepSeek V4 Pro 形成“首次冲顶折返后，第二次冲顶如何成功”的 TopicBrief，并输出完整主体、目标、阻碍、行动、代价和结果。来源局限与推断代价都被保留。资料来源见 [Royal Geographical Society](https://www.rgs.org/our-collections/buy-and-license-images/limited-edition-platinum-prints/everest-1953-limited-edition-platinum-prints)。详细失败谱系见 `../LEDGER.md` 的 A14-A15。
