# ADR-020: 撤下并行选根硬约束，恢复顺序语义链与证据交付

## 状态

`adopted corrective checkpoint; supersedes ADR-019 runtime decision`

## 背景

ADR-019 将 A58 的并行语义工作者作为可用检查点。真实雪茄馆回归显示，该实现不仅改变并发方式，
还用模型生成的上下文绑定和必需语境控制候选资格，使历史、人物和跨域内容被过早判为漂移。恢复前一
架构后，内容根仍会把一个包含场所、消费动作和社交结果的长场景误认成更大世界。后续交付又暴露两类
独立故障：供应商返回完整但 JSON 转义错误的工具参数，以及模型从自身记忆向稿件补入证据外专名和
绝对断言。

## 决策

1. 撤下 ADR-019 对运行时并行首轮和其硬语境门的采用；历史文档、提交和评测保留为失败证据。
2. 内容世界恢复顺序链：语义阅读、语义家族、共同世界、独立反事实复核、单一根裁决、冻结根地图。
3. 根裁决比较候选的真实外延容量。把场所、对象、消费动作和社交结果拼成长名称不自动成为上位世界；
   对象在该场景外仍能展开历史、人物、事件、地域或作品时，场景只是地图路径。
4. 结构化调用最多做一次协议修复。畸形工具参数只作为有界不可信数据返回，修复不得改变判断或增加
   内容；下游孵化、交付与形式运行器复用同一解析边界。
5. MessagePlan 在绑定 BaseDraft 前检查证据外专名、数字、显式新名字和高风险绝对断言；命中后只
   允许一次删除/泛化修复，仍越界则拒绝交付。
6. 当前真实核心验收允许继续到 `FormatDecision -> AdaptedDraft`。账号级表现形式与本条表达形式都
   属于认知判断；信息不足时保持 provisional。`ProductionPlan`、素材和 MediaKit 暂停，已实现后置
   代码不删除也不用于夸大本轮完成度。

## 理由

- 质量回归来自语义合同与硬门变化，不能以并发收益抵消。
- 顺序结构让每个认知产物可见、可重放，符合“先找病根再提速”的当前优先级。
- 场景外延反例是跨行业判断，不是为雪茄写行业答案。
- 协议恢复解决的是供应商兼容；事实护栏解决的是证据泄漏，两者不能混成一个宽泛重试。
- 拒绝第二次语义修复可以避免模型用另一个流畅幻觉掩盖第一次错误。

## 不采用

- 不恢复 A58 的 `required_contexts` 硬门或两路并行运行时。
- 不把雪茄、黄金礼品或宠物殡葬标准答案写进提示词、代码或测试可见输入。
- 不用向量库、行业关键词、固定 MCN 流程或更多 Agent 层掩盖内容根失败。
- 不把高信号词法护栏描述为完整事实核验，也不因一个雪茄案例通过宣称通用验收。

## 后果

- 内容根质量恢复，但完整语义与地图链的真实延迟仍高。
- 宠物殡葬和雪茄均已成为开发证据；下一次通用验收必须使用未见过的新留出题。
- 资料权威性仍由研究层负责。交付护栏不能把零售商来源升级成一手证据。
- 未来若重新并行，必须用新留出集与相同模型、预算、证据比较质量和延迟，并以替换方式实施。
