# A79 内容机会、对标证据与账号策略边界审计

## 审计状态

- 日期：2026-08-18
- 基线：`60098aa2`
- 状态：`adopted`
- 范围：语义、内容地图、对标证据、账号孵化判断、选题交付及其产物谱系

## 用户纠错

账号定位是长期工程，会被账号数据、受众反馈、对标观察和复盘结果修订。它不能由一次语义分析或
一张内容地图永久决定。对标账号同样是独立证据来源，不应藏在生成单条选题的工具里。

## 追踪结果

旧的 `content_intelligence_tool.py` 同时承担四类生命周期：

1. 从用户表达发现内容机会。
2. 搜索资料并选择项目中的对标/受众证据。
3. 生成账号定位、受众、人设、账号级表现形式和变现判断。
4. 生成本条 TopicBrief、MessagePlan、BaseDraft、形式适配和制作方案。

原调用顺序还存在职责倒置：TopicBrief 先完成，之后才临时生成 `IncubationJudgment`。因此定位没有
参与选题，只在交付阶段追加；每做一条内容又可能制造一份新定位。`ContentWorldView` 同时被渲染为
“账号内容定位”，导致婚礼、购买、到店、宴请等局部场景反复争夺长期定位权。

对标链本身已有部分正确边界：正式 `BenchmarkSnapshot` 是稳定身份、多作品一致性和覆盖回执绑定的
只读观察，项目证据选择器不会采用 `benchmark_account_candidate`。但生产抖音采集仍只生成候选证据，
正式快照连接器尚未接通。

## 采用边界

| 模块 | 拥有的判断权 | 明确不拥有 |
| --- | --- | --- |
| 语义与候选内容地图 | 解释用户表达、选择语义入口与候选地图根、展开可研究方向 | 账号定位、受众、人设、表现形式、变现、对标结论 |
| 对标证据 | 稳定身份、作者一致作品、覆盖、公开观察和限制 | 当前用户定位、爆款因果、可复制公式 |
| 账号孵化策略 | 定位、受众假设、人设、账号级表现方向、变现假设及版本修订 | 改写历史语义、候选地图、单条事实证据 |
| 单条选题与成稿 | 从精确地图路径和证据形成今天讲什么、说什么 | 临时创建或修订账号策略 |

## 已实现

- `ContentWorldView` 封存为 `content_map_candidate`，移除账号定位字段和产物宣称。
- 根选择合同将 `content_entry` 与 `map_root` 分开；窄场景 `example_branch` 不可被选为根。
- 已复核共同世界不再由代码隐藏覆盖模型选择，只作为普通候选参与显式裁决。
- 新增 `develop_account_strategy` 高层工具和共享运行支持模块。
- 新增账号策略服务，独立封存 Brief、候选地图、正式证据和版本化判断。
- `IncubationJudgment` 增加版本号、上一版 ID 和修改原因；后继版本校验项目、账号和连续版本。
- 相同父产物集合复用当前版本；变化生成下一版并保留上一版。
- 内容工具不再导入或调用账号判断生成器和正式对标证据选择器。
- 选题链只读取与当前候选地图版本精确匹配的最新有效策略，不存在时不补造。
- Lead 路由把起号/定位交给 `develop_account_strategy`，把内容机会或具体选题交给
  `explore_content_world`。

## 黄金婚礼病根及同类风险

婚礼反复出现并不只是模型偏好。旧结构把“商品进入的一个高频场景”同时当作语义候选、地图方向、
账号定位和本条选题。婚礼一旦在任一层变得具体，就会凭人物和事件丰富度覆盖更大的“礼与人际关系”
世界。相同结构会把海鲜收缩为宴请、水果店收缩为购买、火锅收缩为聚餐、雪茄馆收缩为到店品鉴、
KTV 收缩为社交。现合同以“完整世界和例子分支”的结构角色约束这类问题，不使用行业关键词黑名单。

## 未完成与限制

- 线程当前只绑定项目，没有绑定某个 `PlatformAccountRef`。默认仍是项目级策略，不能宣称已完成
  同项目多平台、多账号策略切换。
- 还没有产品界面的策略采用、切换和历史对比。
- 正式 `BenchmarkSnapshot` 合同可用，但生产稳定身份连接器仍待实现。
- 本轮验证的是职责和谱系，不代表黄金、水果、海鲜、火锅等所有真实营销质量题已经通用通过。

## 结论

本轮采用的不是“再拆几个 Agent”，而是把长期业务对象从一次内容运行中剥离。候选地图可以帮助账号
策略，也可以直接帮助选题；对标只能提供证据；账号策略保留唯一长期判断权；选题只消费已存在的策略。
该边界由 ADR-021 固定。
