# A86 词汇证据候选召回实验预注册

## 状态

- 本地日期：2026-08-19
- 冻结基线提交：`49459ce7`
- 状态：`preregistered before implementation and live output`
- 范围：只验证商业复合词中的完整内容世界能否被召回为候选
- 非范围：最终内容根选择、内容地图、账号定位、选题、知识库检索和生产接入

## 问题

A84 把候选召回与最终选择拆开后，暴露了两种不同失败：

1. 正确候选没有进入图，例如“咖啡豆”漏掉完整的“咖啡”；
2. 正确候选已经存在，但选择器仍选错，例如羽毛球馆案例。

A86 只研究第一种。它不允许改 A84 的选择器，也不允许再用 A84 四题调参。

## 冻结假设

结构化词汇证据可能帮助模型看见复合词中的完整活动或对象，例如：

```text
滑雪服 -> 滑雪
古筝琴弦 -> 古筝
摄影补光灯 -> 摄影
```

但普通子串也会制造错误，例如：

```text
马桶 -/-> 马
巧克力 -/-> 巧 / 克 / 力
沙发 -/-> 沙 / 发
```

因此词库的职责只能是提供可审查候选，不能决定最终内容根。

## 冻结数据

数据集为 `backend/experiments/lexical_candidate_lab/datasets/held_out_v1.json`，共十题：

- 七个透明复合词：滑雪服、冲浪板、古筝琴弦、书法墨汁、围棋棋盘、摄影补光灯、露营天幕；
- 三个防机械拆词对照：巧克力、沙发、马桶。

模型只能看到 `subject_expression` 与 `commercial_object`。`accepted_aliases`、
`forbidden_exact_labels` 和人工理由只允许评测器读取，不得进入模型消息。

这十题在唯一冻结运行后即转为开发证据，不得重跑、调参后继续声称是留出集。

## 比较臂

1. **词典裸候选**：不调用模型，只列出商业对象与 CC-CEDICT 收录的严格真子串。该臂只用于观察
   词库本身的召回和噪声，不参与上线判断。
2. **纯模型**：给定商业对象，用一个固定提示和一次结构化调用开放召回候选，不提供词汇证据。
3. **模型 + CC-CEDICT**：与纯模型使用同一模型、提示、输出合同和调用数，只增加有界、带来源的
   整词义项、真子成分和词族关系证据。

所有模型臂固定：`glm-5-2-260617`、思考关闭、温度 0、不联网、每题一次主调用。词典索引沿用
A30 的只读本地 CC-CEDICT 工件；模型投影不得出现本地路径。

## 输出合同

每题只输出：

- 原始商业对象；
- 最多八个平等候选；
- 每个候选与商业对象的关系；
- 候选依据来自用户字面、词汇证据或模型通识；
- 使用词汇证据时绑定真实证据词；
- 未知与限制。

不输出推荐、不排序、不选择内容根，也不写账号方案或选题。

## 冻结指标

主指标分开统计七个透明词和三个对照词：

1. `transparent_candidate_recall`：七个透明词中是否至少召回一个隐藏接受别名；
2. `guard_forbidden_hit`：三个对照词中是否生成隐藏禁止的机械拆词候选；
3. `contract_success`：合同解析、商业对象保留、候选唯一、证据绑定均通过；
4. 调用数、Token、时延和证据投影字节数只报告，不代替质量门槛。

CC-CEDICT 证据臂只有同时满足以下条件，才能获得“继续离线研究”资格：

- 透明词召回至少 `6/7`；
- 比纯模型至少多召回两题；若纯模型已达到 `6/7` 或以上而不存在两题提升空间，结论应为
  “词库没有证明增益”，不得修改门槛；
- 三个对照词的禁止候选命中为 `0/3`，且不得高于纯模型；
- 合同成功至少 `9/10`；
- 人工复核没有发现靠近义套话冒充隐藏候选、证据引用不存在或借词机械拆解。

即使通过，也只允许下一轮用新题研究“词汇候选补充器”，不允许接入生产、替换现役内容根、建设
向量库或恢复 A84 选择器。

## 预先决定

- 若纯模型已经稳定召回，说明 A84 的咖啡失败更可能来自过载合同或注意力竞争，不建设新知识层。
- 若词典裸候选召回高但噪声也高，保留词库为证据源，拒绝确定性自动并入候选。
- 若模型加证据提升召回但增加机械拆词，判定失败；不能用最终选择器“以后会过滤”替它兜底。
- 若证据臂通过，只说明结构化词汇证据对候选召回有价值，不说明最终营销判断已经解决。
