- 状态：adopted
- 上游：A120、ADR-035
- 代码基线：b69ceb73
- 模型：glm-5-2-260617
- 思考：关闭
- 温度：0
- 机器证据：skills/public/incubate-gift-human-relations/evals/evidence/acceptance-evidence.json

## 问题复现

A120 的四层硬控全部存在。进一步追踪还发现，通用语义链的
_reviewed_cross_domain_family_map_root 会在根裁决器返回后确定性改写 map_root。因此仅把
default_root 改名仍不够，行业 Skill 和通用语义层都会在模型判断之后改答案。

## 测试先行

先增加失败测试，要求：

1. Skill 偏好不得覆盖模型选择。
2. 局部场景可以作为地图或账号路线的支持内容。
3. Profile 不再提供自然语言分类函数。
4. 路由与治理元数据不进入内容根判断上下文，行业 Profile 不得向 Brief 注入事实否定项。
5. 历史 Brief 的 excluded_content_branches 可读取但会被丢弃。
6. 已复核共同世界保留为候选，不能覆盖根裁决器的显式选择。

实现后，六个相关测试模块聚焦回归为 136 passed；内容智能、孵化、Skill 加载、Skill 审查与 Lead
接线的宽回归为 524 passed。后端 Ruff 检查与格式检查均通过。

## 实现

- Profile 升为 schema v3：default_root 改为 preferred_root_candidate，
  branch_only_markers 改为结构化 supporting_branch_hints。
- 删除 _mentions_marker_positively、inactive_map_branches、地图关键词删除、路线全文子串拒绝和
  content_branch_boundary。
- 删除 _reviewed_cross_domain_family_map_root 的裁决后覆盖。
- decision_projection() 只暴露领域候选、原则、可拒绝偏好与支持提示；Skill 名、版本、哈希、路由、
  生命周期和来源均不进入模型上下文。
- 删除 Profile 的 do_not_assume；通用 Brief 继续以用户事实、已确认能力和资源约束下游判断。
- 礼赠 Skill 升为 1.1.0，补充“生活世界优先于理论层级”的可拒绝选择原则；不写 SKU 答案。
- 激活包重新绑定 Skill、Profile、评测、触发集、接收回执和本地证据哈希。

## 真实运行

| 阶段 | 输入 | 结果 | 处置 |
| --- | --- | --- | --- |
| 初始软化 | 黄金礼品 | 礼如何规范人与人之间的相处 | 失败；理论层级仍压过具体生活世界 |
| 增加软比较原则 | 黄金礼品 | 入口为人情世故，但地图根被通用代码改写 | 失败；删除裁决后覆盖器 |
| 最终包 | 黄金礼品 | 入口与地图根均为“人与人之间的相处与人情世故” | 通过，106.516 秒、14745 tokens |
| 最终包反向行为 | 婚礼伴手礼定制 | 原业务与局部地图路径保留，但模型仍选择人情世故总根 | 部分通过；无禁词，但软偏好仍偏强，108.776 秒 |
| 最终包新留出首轮 | 企业客户答谢礼定制 | 最终 FrozenContentMapDraft 在内建修复后仍为空 | 失败，145.695 秒 |
| 有界整链恢复 | 同一企业客户答谢礼 | 入口与地图根均为“人与人之间的相处与人情世故” | 恢复通过，79.3 秒、13262 tokens |

最终黄金地图形成请客饭局、借还钱、托人办事、亲戚边界、职场关系、邻里协商、地域文化、人情规则历史、
面子台阶和话外之音等维度。婚嫁只在局部路径中出现，没有占据根或地图主体。

## 验收边界

- 路由看到的 Skill 名称和短描述与 1.0.1 完全相同，前后路由投影 SHA-256 均为
  3634447078a370a14e2c11752ff64e747a3465244c0ebf973d2ebcc3de06652e，因此复用 A118 的三轮
  8/8 触发与反触发证据；行为性 Profile 与运行时结论使用本轮新证据。
- 最终黄金与明确局部业务各运行一次；企业答谢礼首轮结构失败后做了一次有记录的整链恢复。当前运行时
  只做单节点结构修复，不会自动重跑整链。
- 明确局部业务虽未被删除，最终仍选择偏好总根；这证明硬门已消失，但不能证明软偏好强度已校准。
- 本轮只验收内容根与候选地图，不代表账号定位、脚本、制作或发布已经通过。
- 成功链耗时 79.3 至 108.776 秒、总 Token 13262 至 17047；延迟与成本仍不可接受，后续应单独优化
  模型调用数，不把性能改造混进本次判断权修复。

## 结论

方案比 v2 好用，且架构更接近原始目标：行业 Skill 负责提醒模型往哪里看，模型负责比较和收敛，代码
负责合同与台账。ADR-033 的默认覆盖和自然语言分支硬门被 ADR-035 正式取代。当前结论是“可继续使用
和校准”，不是“行业 Skill 已稳定解决全部内容根判断”。
