# A95 老年助听器内容根与 IP 可行性纠错

## 状态

- 本地日期：2026-08-19
- 来源：用户对 A92 老年助听器案例的事后复核
- 状态：`reviewed -> correction adopted`
- 影响范围：A92 人工解释、内容根合同和后续评测标注协议
- 不修改：A92 冻结数据、提示、唯一运行和原始证据

## 原标注的问题

A92 为“我是卖老年助听器的”预设了两个必须召回概念组：听力健康和老年沟通。模型输出“听觉健康、
衰老与感官退化、老年人与技术的关系、沟通障碍与重建”，因此人工复核把该案例视为完整命中。

这些候选在语义上可以成立，但主要停留在产品功能、疾病后果和技术适应。它们没有回答更重要的营销问题：
谁在为什么购买、老人希望被怎样对待、子女如何面对父母衰老，以及这件商品承载了什么家庭关系和社会价值。

## 用户纠错

更合理的开放层级是：

```text
老年助听器                商业对象
-> 听见与重新参与沟通      直接功能和使用结果
-> 孝亲敬老 / 如何陪父母老去 / 老年生活与代际关系
                           可供选择的更大内容世界
-> 尊重、体面、陪伴等观察视角
-> 父母为什么宁愿听不清，也不愿承认自己需要助听器等具体选题
```

“听力健康”仍可作为听力专家账号的专业内容世界，“沟通重建”也可以成为有效分支；但对于只声明“卖老年
助听器”的主体，不能默认这两个功能性答案就是最佳 IP 内容根。孝亲敬老可以成为完整候选世界，也不能被
机械设为唯一答案，
购买者是否为子女、经营者是否具备专业资质、是否能接触真实老人故事，目前都是未知事实。

## 品类不一定能独立成为 IP

内容根系统此前还藏着一个错误前提：每个商业品类都应该被推导出一个长期 IP 世界。老年助听器可能存在
语义上相关的内容方向，但如果经营者没有专业能力、人物经历、老人授权案例或稳定的一手观察，仅靠品类本身
很难形成可信且可持续的 IP。

因此必须允许内容根判断返回：

- 有强内容世界，可以进入账号定位；
- 有条件成立，需要特定人物主体、证据或素材；
- 只有产品内容或阶段性选题，不足以支撑独立 IP；
- 信息不足，暂不判断。

这不是营销失败，也不是硬门。内容根模块只报告内容世界与成立条件；后续账号定位模块再决定由专家、品牌、
用户故事或其他主体承载，不能为了让流程完整而强行造一个 IP。

- A92 仍然不通过，也不得按新答案重跑；本纠错只改变我们对失败原因的认识。
- A92 的薄候选合同仍有价值，但下一轮必须允许零个强根，并单独表达“是否足以支撑长期 IP”及成立条件。

## 后续标注约束

1. 冻结前先区分直接功能、购买动机、关系世界、价值视角和具体选题。
2. 同时保留专业型、关系型等多个有效根，不能预设一个经营者必然拥有专业身份。
3. 标注可接受的“弱 IP / 条件成立 / 暂无强根”，不能只奖励模型生成更多候选。
4. 关键案例须由用户复核；聚合分数必须显示争议标签，不能掩盖评测答案本身的不确定性。
