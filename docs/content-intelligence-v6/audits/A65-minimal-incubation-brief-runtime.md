# A65 最小项目简报运行时

## 目标

把用户“我是做什么的”先变成可追溯的项目事实，而不是等模型顺手补齐能力、资源、客户、平台和变现。
该产物是孵化判断的事实输入，不是问卷，也不决定内容根。

## 实现

- `build_minimal_incubation_brief` 接收用户整句原话和语义模块冻结的 `source_object`。
- `source_object` 必须是原话中的一个连续逐字片段；改写、拼词和空值直接拒绝。
- 首版只生成一条 `user_stated` 业务事实，引用同一逐字片段；能力、资源、限制、目标、偏好、受众、
  变现和平台不作推测，并留下显式未知。
- 构造过程完全确定性，不接模型、检索、问卷、案例模板或营销规则，再由现有
  `seal_incubation_brief` 完成项目、哈希和来源运行绑定。

## 验证

最小简报、领域合同和孵化判断联合回归 `21 passed`。当前构造器已可进入项目运行链，但尚未在
`explore_content_world` 中调用和持久化；授权观察、后续用户补充和 Brief 版本更新仍需单独实现。
