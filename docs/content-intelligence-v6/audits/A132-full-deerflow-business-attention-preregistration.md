# A132 完整 DeerFlow 业务注意力对比预注册

## 研究问题

在完整 DeerFlow Harness 中，给现役 Lead 增加一张 1382 字节、没有行业答案的业务注意力上下文，能否稳定
提升“我做某项业务，怎样起号”的实际业务判断。这里验证的是业务理解、受众行为、长期内容世界、观察
视角、具体方向、业务回路与事实边界，不是文风、Token 节省或 Prompt 美观。

## 冻结实验臂

1. `current_full`：现役 `DeerFlowClient`、现役完整 Prompt、工具、Skill、MCP 路由和中间件。
2. `focused_business`：同一构造路径、模型、thinking、工具、Skill、MCP 路由和递归预算，只在真实模型请求
   的系统上下文末尾追加一张短业务注意力卡。

两臂使用 `glm-5-2-260617`、thinking 开启、subagent 关闭、独立内存 checkpoint 和全新 thread。执行顺序
按 case ID 稳定交替。候选不得增加工具调用额度、行业示例、隐藏现役 Skill 或修改用户原话。

每个模型请求只保存系统上下文哈希与字节数、模型可见工具名和消息数量；每个 Agent 回执保存最终答案、
工具名序列、调用与结果数量、失败数、Token、耗时、循环检测和终止状态。禁止把工具参数、原始结果、
Cookie、Token、路径或页面正文写进实验回执。

## 冻结数据

黄金礼品只作已知诊断，不参与晋级。六个全新 held-out 覆盖餐饮后厨安全、旧衣纪念玩偶、农用无人机
植保、二手钢琴整备、循环工业包装和社区老年助餐。数据集只含用户原话，不含内容根、推荐路线、标准
选题或行业答案。

黄金礼品的人工标准保持不变：从“黄金”到“送礼”只是部分进步；只有能继续理解礼如何组织人与人相处，
并进入人情世故这一长期世界，才算核心跃迁成功。

## 盲评与晋级

盲评每项 0 至 2 分：

- 完整业务理解；
- 看到、转述、决策、付款、使用与受益的行为链；
- 可长期生长的内容世界；
- 能反复解释现实的观察视角；
- 至少一条具体可讲方向；
- 注意力与信任返回业务的合理路径；
- 不编造用户事实、金额、案例、资源或效果。

候选必须同时满足：六个 held-out 全部有效；两臂首个请求的基础系统 Prompt 哈希和工具目录一致；至少
四题获盲评偏好；平均得分增益至少 1.5 分；无事实边界回归；任一题不得低于现役超过 2 分；裁判调用全部
成功。重复意图、空回答、工具合同不一致或裁判失败都会阻止自动晋级。

自动通过也只进入人工业务复核，不直接修改生产 Prompt。人工复核可以因主体错误、浅层购买场景、虚构
事实或裁判误读否决晋级。若最终采用，应优先替换或动态提供现役孵化段，不得永久叠加成另一层长提示词。
