# A67 表现形式适配稿

## 目的

`FormatDecision` 只回答“这一条用什么形式”，不能直接承担改稿。A67 在 BaseDraft 之后增加独立
`AdaptedDraft`，把同一内容翻译为口述、图文、纯素材、访谈、纪录观察、微短剧或情景剧的可执行表达，
同时不重新打开选题和事实判断。

## 边界

- 适配稿精确绑定 `BaseDraft + FormatDecision`，在模型调用前校验项目、类型、父级、业务 ID、阶段和正文哈希。
- 每个表现单元至少引用一段 BaseDraft 中连续逐字原句，并保存字符位置；无来源单元不能封存。
- 适配合同没有 TopicBrief、MessagePlan、证据、销售、平台、发布、时长、镜头数、频率或配额字段。
- 图文、纯素材等非叙事形式不能被强行加入对白和人物调度；只有微短剧或情景剧允许高层场面与表演提示。
- 输入上限为 24,000 UTF-8 字节；父级、模型或合同失败均不产生半份产物。

## 验证

适配稿、表现形式和关联边界联合回归 `61 passed`，Ruff 与格式检查通过。当前只是可接线的发布前
产物；素材与拍摄方案必须消费这份适配稿，不能越级回到 BaseDraft 另写一套内容。
