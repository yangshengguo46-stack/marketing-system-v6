# A131 A130 人工业务复核

## 结论

A130 的自动晋级无效，薄业务注意力卡暂不进入现役 Prompt、Middleware 或 Skill。问题不在裁判分数本身，
而在实验给 `current_full` 提示词保留了“先发现并读取 Skill”的工具合同，同时又把工具全部关闭。模型在
黄金礼品、TikTok 公会和宠物纪念三题中重复描述将要检查 Skill，没有形成可评答案。候选没有这段合同，
所以获得了不公平优势。

这也暴露了一项真正的 Harness 问题：模型可见的提示、工具目录、Skill 目录与执行能力必须构成同一份可
重建合同。只复制系统提示词不等于复制 Agent。

## 逐案业务判断

| 案例 | 人工结论 | 主要原因 |
|---|---|---|
| 水果店（诊断） | 现役略优或相当 | 两者都偏常见门店内容，现役多了价格透明与实际经营分叉 |
| 黄金礼品（诊断） | 候选仅部分通过 | 能从黄金到送礼，但停在送礼顾问和购买场景，没有进入人情关系世界 |
| TikTok 公会（诊断） | 候选第一问有效 | 正确区分招主播与招合作方，但尚未形成完整方向；基线无效 |
| 工业机器人维修 | 混合，不能记胜 | “机器人医生”更锐利，但擅自生成 20 万和 8 万，事实边界回归 |
| 加装电梯 | 现役更强 | 现役的受众层级、内容支柱和本地业务约束更完整 |
| 老年手机培训 | 现役更强 | 现役解释了子女为何看到、转发、付费，候选只识别了角色分叉 |
| 宠物纪念 | 候选方向真实有效 | 从低频告别服务扩成陪伴、衰老、告别、纪念和思念；基线无效，不能计胜 |
| 企业保密培训 | 候选更强 | 抓到“内容不能泄密但必须证明值得聘请”的核心传播矛盾 |
| 户外移动厨房 | 候选更强 | 从设备展示收敛到户外做饭，设备自然成为解决问题的工具 |

排除三个工具合同失效案例后，候选不是稳定优胜：两个真实提升、两个真实退步、一个大致相当、一个伴随
事实编造。它证明“业务注意力”值得继续验证，也证明单纯追加一段提示词并不能整体提升业务能力。

## 后继实验约束

1. 基线和候选必须由同一个 `DeerFlowClient` 构造路径创建，使用同一模型、thinking、工具、Skill、
   MCP 路由、授权和递归预算。
2. 候选只允许增加一张短注意力上下文；不得更换工具、隐藏现役 Skill、增加行业示例或调用额度。
3. 使用全新 held-out；已看过的 A130 案例只能作诊断，不得决定晋级。
4. 回执必须记录每轮实际工具名、调用次数、Token、耗时和终止状态。重复意图或循环直接判该臂失败。
5. 自动裁判之后仍需人工复核业务主体、受众行为链、长期内容世界、观点、回路和事实边界。
6. 黄金礼品若作为诊断，标准仍是能否越过直接购买场景，到“人与人相处与人情世故”；“送礼顾问”不算
   完整通过。
