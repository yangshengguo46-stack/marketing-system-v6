## 用户纠错

A92 把房车租赁案例的第二个必须召回概念预先标为“自驾旅行 / 自驾游 / 公路旅行”。这个标注过窄，
仍然把内容世界绑在交通方式上，没有完成从载体到更大世界的迁移。

正确的语义层级是：

```text
房车租赁        商业对象
-> 房车旅行     产品直接进入的使用世界
-> 旅行         可以独立成立的更大内容世界
-> 自由、户外、移动生活等长期观察视角
-> 欧洲人一般都怎么旅游等具体选题
```

“自驾旅行”和“公路旅行”可以是旅行世界中的分支，但不应取代“旅行”本身。自由、户外和移动生活也不是
这道题唯一正确的内容根，而是可供账号选择的长期视角或相邻内容领地。具体人物、地区、时间和事件应留给
内容地图与选题生成。

## 对 A92 的影响

- 冻结案例中的第二个概念组标记为 `contested`，不得在原文件中改写。
- A92 输出了“房车旅行、房车生活、移动居住”，命中了直接使用世界，但没有把“旅行”作为独立候选召回。
- 因此 A93 的人工召回数字方向上不变：该案例仍缺一个更大世界；未命中名称从“自驾旅行”修正为“旅行”。
- A92 仍未达到生产门槛，本纠错不用于事后宣布通过，也不触发重跑。

## 新的标注约束

后续内容根评测不能再由开发者用一个未经复核的单一标准答案代表用户判断。冻结前必须：

1. 区分商业对象、直接使用世界、更大内容世界、长期观察视角和具体选题。
2. 为同一案例记录多个可接受答案组，并说明哪些答案只是分支、载体或视角。
3. 由用户复核关键迁移案例；存在分歧时标为 `contested`，不能把评分器判断冒充业务真相。
4. 验收“是否召回可成长的世界”，而不是强迫模型复述开发者预先选择的唯一词语。

本次纠错进一步支持当前方向：单智能体负责开放召回，用户拥有最终内容根选择权；搜索、对标和内容地图只在
内容根确认后提供证据和展开，不能代替这一步判断。
