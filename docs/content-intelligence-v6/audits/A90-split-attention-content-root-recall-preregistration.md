# A90 分离注意力的内容根候选召回实验预注册

## 状态

- 基线提交：`c5d86de8`

- 范围：只验证“商业表达 -> 多个语义成立的候选内容根”
- 非范围：候选排序、最终选根、抖音对标、内容地图、账号定位和生产接入

## 问题重述

A84 把候选生成与最终选择绑在同一实验，候选召回 `3/4`，选择 `2/4`。A86 和 A88 继而
证明词典子串与精确词义不能弥补这个缺口；A88 纯模型候选召回反而达到 `6/7`。

因此 A90 不再让候选工作者判断“哪个最好”，也不给它词典、开发示例或抖音数据。本轮只问：

> 把一次容易被商品词面占满的开放召回，分成两个互不可见的注意力视角，是否能提高完整内容世界召回，
> 同时不把词面残片和任意“生活/文化/关系”混进来？

## 冻结数据

`backend/experiments/content_root_recall_lab/datasets/held_out_v1.json` 共十二题，与 A84、A86、A88 及
ContentRootLab 开发例全部不重合：

- 九个迁移案例：商务伴手礼、儿童绘本书架、露营炊具、宠物殡葬服务、孕妇枕、茶具、剧本杀店、
  登山杖、祭祀鲜花；
- 三个词汇化对照：夫妻肺片预制菜、鸳鸯锅底、狮子头半成品。

每题的商业对象是本轮已冻结的上游观察，会进入模型输入。必须召回的概念组、可接受别名、禁止标签
和复核理由只供评测器使用，不得进入任何模型消息。十二题共有十六个必须召回概念组。

## 固定比较臂

1. **单工作者开放召回**：每题一个结构化模型请求，同时检查对象、活动、实践、关系和文化世界。
2. **双工作者分离注意力**：两个互不可见的请求并行执行：
   - `object_activity`：只找词内仍成立的完整对象、当前对象服务的完整对象，以及参与者反复进行的活动；
   - `human_practice`：只找对象存在背后的反复人类实践、关系、仪式、共同问题或文化世界；无自然路径可以留空。

确定性代码按轮转顺序合并两个工作者的候选、去重并绑定来源，保留冻结商业对象，最多十个候选。代码不评分、
投票、重命名、合并近义词或选择内容根。

两臂固定使用 `glm-5-2-260617`、温度 0、关闭隐藏思考、不联网、不使用词典、不使用开发示例。

## 合同与输入预检

- 模型只输出候选标签、从冻结商业对象到该候选的连续语义路径、完整世界理由、限制和未知。
- 商业对象候选由代码添加；工作者输出不含候选 ID、来源、分数、排名或选中项。
- 所有非商业对象路径必须从商业对象精确开始，连续到候选精确标签，最多四步。
- 三类模型消息每题均不超过 4 KB，不包含隐藏标签、本地路径、证据索引或开发案例。
- 预检在任何模型请求前覆盖全部十二题；任何输入失败时整轮以零请求终止。

## 冻结指标与验收

1. 概念组召回：十六组中命中多少；
2. 完整案例召回：十二题中多少题命中该题全部概念组；
3. 三个词汇化对照的禁止标签命中；
4. 合同成功、模型请求、Token、用时和每题候选数；
5. 人工复核所有路径是否语义连续，是否用卖方运营、普通购买步骤、产品邻接或任意大词凑候选。

双工作者臂只有同时满足以下条件，才获得后续抖音对标验证的离线资格：

- 概念组召回至少 `14/16`，完整案例召回至少 `10/12`；
- 比单工作者至少多召回三个概念组；若单工作者已达 `14/16` 而没有三组提升空间，结论为“未证明需要分离工作者”；
- 禁止标签命中为 `0`，且不高于单工作者；
- 十二题合同全部成功，没有隐藏标签、本地路径或来源自报泄漏；
- 单工作者初始请求固定十二次，双工作者初始请求固定二十四次；结构修复上限分别为两次和三次；
- 双工作者总 Token 不超过单工作者的 2.25 倍；
- 人工复核没有成体系的虚假语义路径或通用大词漂移。

即使通过，A90 也不能注册为生产 Tool、Skill、MCP、中间件或子 Agent。通过只允许下一轮将冻结候选
分别交给抖音对标证据验证。
