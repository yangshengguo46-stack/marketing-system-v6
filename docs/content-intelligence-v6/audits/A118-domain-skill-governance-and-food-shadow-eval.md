# A118 行业 Skill 治理与食材影子评测

- 日期：2026-08-20
- 状态：reviewed
- 上游决策：A117、ADR-034
- 机器证据：`evidence/a118-domain-skill-governance-and-food-shadow-2026-08-20.json`

## 本轮目标

将 A117 的领域 Skill 架构从文档落到代码，同时保证两个边界：行业方法可按需影响内容根
判断，但新行业包不能因一次成功就进入现役主脑。

## 代码合同

`IncubationSkillProfile` 升级到 schema v2，增加：

- 语义化版本 `profile_version`。
- `candidate / shadow / active / contested / superseded / retired` 生命周期。
- 来源、适用边界、反触发边界和选择原则。
- 无静态标准答案的 principle-only Profile。

通用 Skill parser 把 `SKILL.md`、Profile 和评测 manifest 视为一个激活包：名称、版本、`active`
生命周期、通过回执和被验收 Profile 的 SHA-256 全部一致，正文才会进入 Skill 索引。Profile loader
再次执行类型化校验；评测必须同时具备 trigger、anti-trigger、behavior 和 held-out，每条都要有非空
输入和预期结果，不能用四个只有类型名的空壳条目绕过。Profile 不得同时声明相同适用和排除条件，也不得
在无候选路径且无选择原则时加载。
旧 schema 不做静默兼容，而是返回明确的 v2 迁移错误。文件读取与 UTF-8 错误统一转成领域错误，
不会绕过账号工具的失败边界。

## 礼赠包治理

`incubate-gift-human-relations` 固定为 `1.0.1 / active`，补齐 MIT 许可、来源、适用/反触发
边界及 trigger、anti-trigger、behavior、held-out 四类评测。A116 的真实黄金礼品运行仍是
其行为通过依据；本轮没有用新案例改写该礼赠路径。

标准 Skill 审查已识别 4 个正触发与 4 个反触发，零警告。用现役 GLM 只读延迟索引名称和短描述进行
真实选择：`1.0.0` 首轮为 `7/8`，将黄金礼品误当成被排除的珠宝/投资；因此只修正触发描述并
升为 `1.0.1`。新版本三轮均为 `8/8`，正确区分黄金礼品、黄金投资、珠宝、婚庆和腕表。
另外，“我不做婚礼”、“与婚礼无关”、“跟婚礼没关系”、“别讲婚礼”、“不想碰婚礼”和“非婚礼业务”
都会继续保持婚礼分支禁用，不会因为文本中出现“婚礼”二字反向解禁。

## 食材候选设计

食材包不写入“水果店 -> 水果”等静态答案，只提供一组可迁移的比较原则：

1. 区分完整食物、中间载体、卖方操作、购买步骤、食用场景和社交功能。
2. 水果、海鲜等完整品类可保持为根。
3. 底料、料包等中间载体必须与它最终完成的具名食物比较。
4. 最终只选一个最小完整根，不得拼出混合内容根。

该包只存于 `backend/experiments/incubation_skill_lab/`，状态为 `0.1.0 / shadow`，未进入
`skills/public/`，现役 loader 也会确定性拒绝它。

## 首次真实对照

同一 `glm-5-2-260617`、关闭思考、温度 0，保持现役分析链不变。

| 案例 | 无 Skill 根 | 影子 Skill 根 | 结果 |
| --- | --- | --- | --- |
| 水果店 | 水果 | 水果 | 保真通过 |
| 海鲜 | 海鲜 | 海鲜 | 保真通过 |
| 重庆火锅底料 | 火锅底料与围炉共食的世界 | 火锅 | 改进通过 |
| 咖啡胶囊（新留出） | 未重跑 | 咖啡胶囊 | 失败，目标为咖啡 |

咖啡案例的失败不在最后裁决：上游候选集中根本没有“咖啡”，只有咖啡胶囊、冲泡、
日常消费和功能描述。当前 principle-only Profile 只能评判已生成候选，不能选择一个没被
语义层召回的完整对象。

## 结论

- 行业 Skill 拆分方向有效：它在不改通用主脑的情况下修正了火锅底料的混合根，且没破坏
  水果与海鲜。
- 当前实现还不足以泛化：它仅影响候选生成后的裁决，无法修复候选召回缺失。
- 食材包保持 `shadow`，不注册、不触发、不影响用户当前回答。
- 下一个候选不应再增加静态行业答案；应以新版本和新留出集验证“有界的候选召回提示”，
  并保持候选召回与最终选择两个可观测切面。
