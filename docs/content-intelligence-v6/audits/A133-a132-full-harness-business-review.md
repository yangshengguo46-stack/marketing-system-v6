# A133 A132 完整 Harness 业务复核

## 结论

A132 是一次可比较的完整 DeerFlow A/B，但候选业务注意力卡没有形成稳定的业务能力提升，不能接入现役
Prompt、Middleware 或 Skill。六个 held-out 中自动裁判只给候选三个偏好，其中社区助餐同分；候选平均
得分比现役低 `0.167`，旧衣纪念玩偶单题从 `14` 分降到 `6` 分，且餐饮后厨题裁判结构化失败。候选未
达到预注册的胜题数、平均增益、单题回归和裁判完整性要求。

这不是“注意力完全没用”。它在农用无人机植保题中显著改善了受众代入、长期内容世界、观察视角和事实
边界，在循环工业包装和社区助餐中也补强了角色传递链。但它同时会让模型过早寻找业务分叉并停下来问
问题，压过现役 Skill 已经给出的更深内容世界。它适合作为离线诊断维度，尚不适合作为每轮常驻上下文。

## 实验可比性

- 两臂都由同一个 `DeerFlowClient` 构造，模型均为 `glm-5-2-260617`，thinking 开启，subagent 关闭。
- 七题首个请求的基础系统 Prompt 哈希、十项工具目录、工具 Schema 哈希和模型合同全部一致。
- 两臂使用相同 24 项启用 Skill、MCP 路由、中间件与递归预算；候选唯一差异是追加 1382 字节上下文。
- 黄金礼品和旧衣纪念玩偶两题，两臂真实工具序列完全相同，均为 `describe_skill -> read_file`。
- 回执只保存答案、哈希、工具名、Token、耗时和状态，没有保存工具参数、结果正文或凭证。

因此这轮测到的不是 A130 那种工具合同不一致，而是额外注意力对同一 Harness 推理与工具结果整合方式的
真实影响。

## 逐案业务判断

| 案例 | 人工结论 | 主要原因 |
|---|---|---|
| 黄金礼品（诊断） | 两臂都通过，候选仅略优 | 现役已经越过黄金与购买场景，明确推荐“人情世故视角”，能讲面子、人情债、回礼、边界和身份变化；候选没有独占这次跃迁 |
| 餐饮后厨安全 | 相当，不能计胜 | 两者都抓到现场反差、安全焦虑和本地 B2B 信任；候选稍聚焦，现役稍完整，但都混入未取证的平台分发和转化常识，且裁判失败 |
| 旧衣纪念玩偶 | 现役决定性胜出 | 现役找到“那些舍不得扔的东西”和父母面对时间流逝的情感记忆世界；候选过早追问“定制服务还是分享手作”，没有给出当前事实下的方向 |
| 农用无人机植保 | 候选决定性胜出 | 候选形成“站在种植户田边解决真问题”的本地植保实战视角；现役停在通用清单，还擅自写入具体虫情、天气和客户反馈素材 |
| 二手钢琴整备 | 平局 | 两者都找到“钢琴重生记录”、整备过程反差以及卖琴或服务的回路，没有实质业务差异 |
| 循环工业包装 | 候选小幅胜出 | 候选区分观看者、询价者、拍板者和付款者；两者仍偏成本说服，没有形成足够强的长期内容世界 |
| 社区老年助餐 | 基本平局，候选表达略优 | 两者都识别成年子女决策、老人使用；候选多写了一步转述链，但同为 `11` 分，业务回路和内容世界仍不够深 |

候选的真实能力增量集中在“谁看到、如何代入、谁转述、谁决策、信任怎样回到业务”。它没有稳定提高
“长期讲什么”和“从什么独特视角观察现实”，而这两项才是当前产品最看重的护城河。

## 黄金礼品的关键变化

黄金礼品现役臂本轮已经能到达“人与人之间的相处与人情世故”，并给出三条实质路线：产品、送礼场景、
人情关系，最终推荐第三条。它明确说明内容可以不出现产品，转而观察面子、人情债、互惠、边界、身份变化
和关系远近。这说明第六版现役 Agent 在真实 Skill 和工具可用时，已经具备此前长期缺失的语义跃迁。

候选在该题为 `12` 分、现役为 `11` 分，但两臂都调用相同 Skill 工具，候选多消耗 `2,485` Token。这个
结果支持“现役渐进披露已经生效”，不支持“必须再给总脑常驻一张业务卡”。

## 成本与运行行为

六个 held-out 的现役总消耗为 `59,200` Token，候选为 `63,014` Token，增加 `3,814`，约 `6.4%`。
包括黄金诊断在内，现役为 `77,114`，候选为 `83,413`，增加 `6,299`，约 `8.2%`。七题中候选没有一题
比现役更省 Token。

工具行为没有出现权限、Schema 或路由差异：黄金礼品和旧衣纪念玩偶各调用两项相同工具，社区助餐各调用
一次 `describe_skill`，其余题均由 Lead 一次直接回答。额外成本主要来自常驻上下文和更长生成，而不是
获得了更多证据或能力。

## Harness 含义

1. 同模型、同工具、同 Skill 不等于同业务结果；附加上下文会改变模型如何使用同一份工具证据。
2. 渐进披露确实有效。现役在黄金礼品和旧衣纪念玩偶加载 Skill 后，已经给出本轮最强的长期内容世界。
3. 常驻业务卡会制造注意力竞争。其“实质分叉先澄清”原则在信息确实缺失时有价值，但也会把本可继续
   判断的题截断成追问。
4. 下一步不应再堆一层 Prompt，也不应新增确定性业务闸门。应先保留现役，让业务注意力维度用于离线评测
   和人工复核；若以后验证动态提供，必须使用全新案例，并与“现役直接回答”比较实际增益。

## 决定

- 保持现役 Agent、工具和 Skill 路由不变。
- 不注册 A132 的 Probe Middleware，不把 1382 字节注意力卡追加到生产系统提示词。
- 冻结 A132 七题与唯一正式回执，不重跑、不调参、不把答案变成运行时行业示例。
- 保留请求清单、工具 Schema 哈希和模型合同观测方法，作为 ADR-041 `PromptManifest` 的实验依据；正式
  观测仍须保持无行为影响。
- 将“受众行为链、长期内容世界、观察视角、具体方向、业务回路、事实边界”保留为业务验收量表，而不是
  每轮必须逐项输出的流程。
