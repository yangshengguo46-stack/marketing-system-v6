# A66 孵化判断进入内容交付的边界

## 问题

A63 已能生成定位、受众、人设、账号级表现形式和变现判断，但 `MessagePlan` 与 `BaseDraft`
仍只读取用户原话、冻结地图和 TopicBrief。这样“完整孵化脑”虽然存在，实际成稿却没有使用它，
产物图也无法证明哪一版判断参与了表达。

## 实现

- `synthesize_shooting_delivery` 可选接收与冻结地图版本完全一致的 `IncubationJudgment`。
- 只把定位、受众假设、人设、账号级表达方向、未知和备选投影给内容交付；变现假设不进入
  TopicBrief 或基础文案。
- 孵化判断只能校准账号观察立场、受众解释重点和账号角色，不能重选内容根、选题、事实或
  单条表现形式。
- 当内容交付确实使用孵化判断时，封存的 `message_plan` 同时绑定精确 `topic_brief` 与
  `incubation_judgment`；`topic_brief` 的父级保持为阅读和冻结地图，防止营销判断反向污染阅读。
- 不允许把不同项目、错误类型或不同地图版本的判断挂到本轮交付；没有交付时也不能伪造该父级。

## 验证

Brief、孵化判断投影、内容交付和产物谱系聚焦回归 `25 passed`。本切片完成的是运行边界与
谱系，不等于内容工具已经自动创建和持久化孵化判断；项目读取、对标/受众证据选择和主链编排继续进行。
